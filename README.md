# ReMatter
### Your waste, someone else’s raw material.

ReMatter is an AI-powered platform that identifies, classifies, values and matches industrial waste and by-product streams with manufacturers who can use them as production inputs. Companies upload basic information about a waste stream, including photos, material type, quantity, location and any specifications, and the platform uses AI to identify the material, suggest realistic reuse applications, estimate its economic value, find potential buyers and quantify the carbon and waste-diversion impact of the match.

## Setup
On the terminal, run the following commands
```
1. pip install -r requirements.txt
2. streamlit run app.py
```
